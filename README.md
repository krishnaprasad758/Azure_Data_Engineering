# Azure Data Engineering

A collection of **Azure Data Engineering projects, hands-on implementations, and learning resources** covering data ingestion, transformation, cloud storage, analytics, and reporting.

## 🛠️ Technologies

- **Azure Data Factory (ADF)**
- **Azure Data Lake Storage Gen2 (ADLS)**
- **Azure Databricks & PySpark**
- **Microsoft Fabric**
- **Azure SQL**
- **Power BI**
- **SQL**
- **Python**

## 📂 Repository Highlights

This repository contains practical projects demonstrating:

- End-to-end data engineering pipelines
- ETL/ELT workflows
- Medallion architecture — Bronze, Silver & Gold
- Incremental data loading and watermarking
- Data cleansing and transformation using PySpark
- Azure Data Factory orchestration
- Data lake and lakehouse concepts
- Power BI analytics and dashboards
- SQL and data engineering practice

## 🏗️ Typical Data Flow

```text
Data Sources
     ↓
Azure Data Factory / Fabric
     ↓
ADLS / OneLake
     ↓
Bronze → Silver → Gold
     ↓
Databricks / PySpark
     ↓
Power BI
```

## 🎯 Purpose

The goal of this repository is to document my **hands-on journey in Azure Data Engineering** and showcase practical projects that demonstrate cloud data engineering concepts and real-world data workflows.
